03 Permiso por herramienta y rol

  
Permiso por herramienta y rol.

  

    
AlcanceHerramientas.java

    
    static boolean puedeUsar(String herramienta) {
        Set<String> roles = ROLES_POR_HERRAMIENTA.get(herramienta);
        return roles != null && tieneAlgunRol(roles);
    }


    
Qué hace: Si el rol no aparece en la lista, la herramienta no se ofrece al modelo.

  


  
04 La confirmación es una herramienta aparte, no un efecto de la lectura

  
La confirmación es una herramienta aparte, no un efecto de la lectura.

  

    
HerramientasAccionesMcp.java

    
    @Tool(name = "confirmar_accion",
          description = "Confirma una acción pendiente con su identificador y su código de confirmación. "
                  + "Solo funciona para la persona que la preparó y dentro de su vigencia. "
                  + "Un código incorrecto cancela la acción.")
    public String confirmarAccion(
            @ToolParam(description = "Identificador de la acción preparada", required = true) String accionId,
            @ToolParam(description = "Código de confirmación de 8 dígitos que devolvió la preparación", required = true) String codigo) {
        RegistroHerramientasUsadas.registrar("confirmar_accion");
        return confirmaciones.confirmarConCodigo(UUID.fromString(accionId), usuarioActual(), codigo);
    }


    
Qué hace: El modelo puede pedir confirmar, pero el cambio exige el código de 8 dígitos.

  

  
Regla del proyecto: la IA propone o prepara; la persona confirma con el código de 8 dígitos. Ninguna herramienta de escritura cambia datos por sí sola.
