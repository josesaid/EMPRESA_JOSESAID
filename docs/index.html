What it does

Eleven services

Nine business services plus a service registry (Eureka) and a single API gateway. Each business service owns its own PostgreSQL database and user.

Secured by design

Access tokens are signed with RS256. Services validate them with the public key from a JWKS endpoint, so no shared secret is needed. Internal endpoints are hidden from outside the gateway.

Idempotent writes

Optional Idempotency-Key header on orders, payments, journal entries, inventory movements and purchase orders. A repeated request returns the original response; keys are valid for 24 hours.

Encrypted sensitive data

AES-256 encryption for supplier tax data and legal documents, with an HMAC index so records can still be found without exposing the raw values.

Observable

Prometheus metrics, Grafana dashboards, Jaeger traces across services, and Kafka UI to inspect topics and messages.

Run it locally

Requirements: Docker 24+ and Docker Compose 2.20+. Free ports: 5432, 8080 and 9092.

docker network create empresa-net          # shared external network, once
cp .env.example .env                       # complete the passwords and keys
cp clientes-ms/.env.example clientes-ms/.env
docker compose up -d --build

Generate passwords with openssl rand -base64 24 and encryption keys with openssl rand -base64 32. The full list of environment variables is in the README.
