Qué hace

Mide la cobertura de pruebas (líneas y ramas) y puede fallar el build si no se alcanza el mínimo configurado.

Plugin y versión

Pluginjacoco-maven-plugin
Versión0.8.12
Goalsprepare-agent, report, check

Configuración en pom.xml

<configuration>
                            <haltOnFailure>true</haltOnFailure>
                            <rules>
                                <rule>
                                    <element>BUNDLE</element>
                                    <limits>
                                        <limit>
                                            <counter>LINE</counter>
                                            <value>COVEREDRATIO</value>
                                            <minimum>0.71</minimum>
                                        </limit>
                                    </limits>
                                </rule>
                            </rules>
                        </configuration>

Cómo ejecutarlo

mvn -f documentos-cumplimiento-ms/pom.xml verify
