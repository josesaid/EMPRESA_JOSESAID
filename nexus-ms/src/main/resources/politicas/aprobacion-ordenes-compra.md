# Política de aprobación de órdenes de compra

1. Toda orden de compra la crea un usuario con rol COMPRAS.
2. Una orden menor a 1,000,000 USD (equivalente a 18,000,000 MXN con tipo de cambio de 18) la puede aprobar COMPRAS.
3. Una orden de 1,000,000 USD o más requiere aprobación de DIRECCION.
4. Ningún usuario puede aprobar una orden que él mismo creó.
5. El total se convierte a USD con el tipo de cambio vigente de la empresa.
